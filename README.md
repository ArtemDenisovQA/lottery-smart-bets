# lottery-smart-bets

CLI-проект на Python для анализа выигрышных комбинаций и генерации новых ставок.  
Дополнительно в проекте есть Telegram-бот, который использует ту же логику и ту же базу данных.

## Что умеет проект

- хранить историю выигрышных комбинаций;
- добавлять новые комбинации вручную;
- анализировать частоту выпадения чисел;
- учитывать частоту в последних 5 и 10 тиражах;
- учитывать текущий пропуск числа;
- учитывать относительный пропуск по сравнению со средним;
- генерировать новые ставки в нескольких стилях;
- запускаться как через CLI, так и через Telegram-бота.

## Как устроена модель

Для каждого числа рассчитываются признаки:

- **общая частота** — сколько раз число выпадало за всю историю;
- **recent_5** — сколько раз число выпадало в последних 5 тиражах;
- **recent_10** — сколько раз число выпадало в последних 10 тиражах;
- **gap** — сколько тиражей прошло с последнего появления числа;
- **avg_gap** — средний пропуск между появлениями;
- **overdue_ratio** — насколько текущий пропуск велик относительно среднего.

На основе этих признаков строятся веса, после чего модель генерирует новые ставки.

## Стили генерации

Проект поддерживает несколько режимов:

- **conservative** — больший упор на частые и относительно стабильные числа;
- **balanced** — баланс между частотой, свежими тиражами и пропусками;
- **risky** — больший упор на редкие и давно не появлявшиеся числа;
- **diversified** — более разнообразные комбинации с меньшим повторением внутри одной серии ставок.

## Требования

- Python 3.12+
- macOS, Linux или Windows
- отдельное виртуальное окружение `.venv`

## Установка

Создай и активируй виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

Установи зависимости:

```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
pip install -e .
```

## Запуск CLI

```bash
python main.py
```

CLI позволяет:

- посмотреть статистику;
- добавить одну комбинацию;
- добавить несколько комбинаций;
- сгенерировать новые ставки;
- посмотреть всю историю.

## Напоминания в CLI

При запуске CLI проект умеет показывать напоминания:

1. если новые выигрышные комбинации не добавлялись больше 7 дней;
2. если в истории накопилось 100 или больше комбинаций и пора добавить бэктест и подбор коэффициентов.

Важно: это не фоновые уведомления. Напоминания показываются при запуске программы.

## Формат комбинации

Ожидаемый формат:

```text
3 4 7 19 23 28 31 + 50
```

Где:
- 7 основных чисел — от 1 до 35;
- 1 дополнительное число — от 1 до 55.

## Хранение данных

История комбинаций хранится в файле:

```text
data/winning_combinations.json
```

Служебное состояние напоминаний хранится в:

```text
data/app_state.json
```

## Запуск Telegram-бота

Бот использует ту же бизнес-логику, что и CLI, и работает с тем же JSON-файлом.

### 1. Создай бота через BotFather

В Telegram:
- открой `@BotFather`
- отправь `/newbot`
- задай имя и username бота
- получи токен

### 2. Создай `.env`

Скопируй шаблон:

```bash
cp .env.example .env
```

Пример содержимого `.env`:

```env
TELEGRAM_BOT_TOKEN=your_real_token
TELEGRAM_ALLOWED_USER_ID=
TELEGRAM_ALLOWED_USERNAME=Arcanzas5000
```

### 3. Запусти бота

```bash
python -u bot.py
```

## Доступ к боту

На текущем этапе можно ограничить доступ:

- по `TELEGRAM_ALLOWED_USERNAME`
- или по `TELEGRAM_ALLOWED_USER_ID`

Надёжнее использовать `user_id`, но для первого этапа допустимо ограничение по username.

## Команды бота

- `/start` — приветствие и помощь
- `/help` — справка
- `/stats` — статистика по истории
- `/history` — последние комбинации
- `/bets balanced` — 2 сбалансированные ставки
- `/bets conservative` — 2 консервативные ставки
- `/bets risky` — 2 рискованные ставки
- `/add 3 4 7 19 23 28 31 + 50` — добавить комбинацию

Также можно просто отправить боту строку комбинации без команды.

## Editable-режим

Проект устанавливается в editable-режиме командой:

```bash
pip install -e .
```

Это значит, что Python использует код прямо из рабочей папки проекта, и после правок не нужно переустанавливать пакет заново.

## Ограничения текущей версии

- история хранится в JSON, а не в базе данных;
- CLI и бот используют один и тот же файл данных;
- при параллельной активной записи из нескольких процессов JSON менее надёжен, чем SQLite;
- напоминания в CLI не являются фоновыми уведомлениями;
- модель не предсказывает выигрыш, а только системно ранжирует и отбирает числа по статистическим признакам.
