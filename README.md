А у# lottery-smart-bets

CLI-проект на Python для анализа выигрышных комбинаций и генерации новых ставок.

Модель учитывает:
- общую частоту выпадений
- частоту в последних 5 и 10 тиражах
- текущий пропуск
- относительный пропуск по сравнению со средним

## Запуск

```bash
source .venv/bin/activate
python main.py
```

## Тесты

```bash
pytest
```
